# Health Considerations in Climate Action: A Text Analysis of Nationally Determined Contributions

This repository contains the code and dataset used for the research paper:

**"Health Considerations in Climate Action: A Text Analysis of Nationally Determined Contributions Texts from Paris Agreement Nations."**

**Authors:** Han Jiang, Shitta Aspendira Dharmastuti, Dzulfikar Ahmad Furqon, Sofiarti Dyah Anggunia, Kwabena Ampong Kutin-Buah, Julius Mugwagwa*, and Jessica Gong.

## 1. Research Overview

Climate change is increasingly recognised as one of the major public health challenges of the 21st century. This study examines how health considerations are reflected in national climate policies through an analysis of the latest English-language Nationally Determined Contributions (NDCs) submitted by countries under the Paris Agreement.

The study covers **75 distinct NDC documents representing 101 countries** and employs a mixed-methods approach, combining text analysis and comparative analysis to investigate the scope and specific direction of health considerations in national climate policies.

The analysis explores the representation of health-related considerations across countries, comparing keyword frequencies at two levels to examine both direct health references and broader climate–health-related language.

### Main Code: `all codes.R`

This R script contains the main analytical procedures used in the study. It uses R packages to extract and process text from NDC documents and conduct text-mining analysis.

The main analytical steps include:

- Extracting text from NDC PDF documents.
- Processing and preparing document text for analysis.
- Calculating word frequencies and percentages across documents.
- Applying a two-level keyword frequency approach to identify and examine health-related considerations.
- Comparing the frequency and percentage of health-related terms across countries.
- Generating figures and tables to support the research findings.

### Dataset: `Dataset/`

This folder contains the NDC documents collected for the study, covering 101 countries.

To maintain consistency and improve the accuracy of the text-frequency analysis, **only the main body text of the NDC documents was included**. Front matter, references, and other supplementary sections were excluded where applicable.

### Output: `Output/`

This folder contains the figures and tables generated by the R code. These outputs were used to support the analysis and present the findings in the research article.

## 3. Methodology

The study applies a mixed-methods approach, combining computational text analysis and comparative analysis of national climate policy documents.

The analysis focuses on:
- The frequency and percentage of direct health-related terminology.
- The frequency and percentage of broader climate–health-related terminology.
- Comparisons of health considerations across countries and income groups.
- The scope and thematic direction of health considerations in national climate policies.

## 4. Software and Requirements

The analysis was conducted using **R**.

The required R packages and dependencies are specified in the main script (`all codes.R`). Please ensure the necessary packages are installed before running the analysis.

## 5. How to Use

1. Clone or download this repository.
2. Ensure that R and the required packages are installed.
3. Set the working directory to the repository location.
4. Run `all codes.R` to execute the text extraction, processing, and analysis procedures.
5. The resulting figures and tables can be found in the `Output/` folder.

Please ensure that the dataset folder structure is maintained so that the code can locate and process the NDC documents correctly.
